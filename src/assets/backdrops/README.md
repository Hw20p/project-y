# 배경 그림 넣는 곳

**그림 파일만 넣으면 바로 배경이 바뀐다.** 코드를 고칠 필요가 없다. (개발 서버를 켠 채로 넣으면 새로 고침, 빌드할 때는 자동으로 묶인다. 소리 파일과 같은 방식이다.)

```
src/assets/backdrops/
  <시나리오 id>/
    <장소>.webp          낮(기본) 그림 — 불이 켜진 모습
    <장소>-night.webp    밤 그림 (선택)
```

- 시나리오 id는 `b7-lobby`, `vending`이고, 장소는 아래 표의 이름이다. 확장자는 `webp` · `png` · `jpg` · `jpeg` · `avif`.
- **밤 그림이 없으면 낮 그림을 코드가 어둡고 푸르게 보정**해서 보인다. 그림 한 장으로 시작하고, 밤이 특별히 달라야 하는 장소만 `-night` 그림을 따로 넣어도 된다.
- 이야기가 정한 어둠(정전)이 켜져 있으면 낮이어도 밤 모습으로, 조금 더 어둡게 보인다. **그림 파일이 없는 장소는 배경을 그리지 않아 기존 배경만 보인다.**
- 개발 중에는 브라우저 콘솔에서 `__backdrops()`를 부르면 어떤 장소에 그림이 연결됐는지 표로 나온다.

## 권장 규격

- 비율 **16:9** (예: 1920×1080). 화면 크기에 맞춰 꽉 채우고(`cover`) 가장자리가 잘릴 수 있으니, **중요한 것은 가운데**에 둔다.
- 글 칼럼(화면 가운데)이 그림 위에 얹힌다. 그림 위에 어두운 막이 덮이므로 **대비가 약하고 어두운 그림**이 글을 읽기 좋다. 밝은 낮 그림도 막 때문에 어두워진다.
- 용량은 장당 **300KB 안팎**(webp)이 좋다. 장면이 바뀔 때마다 불러온다.

## 장소 (과제 하나가 장소 하나)

### `b7-lobby`

| 장소 | 나오는 곳 | 그림 |
| --- | --- | --- |
| `lobby` | 도착, 사건(발소리·전화), 로비의 밤, 마지막 선택, 서명 | 카펫이 깔린 작은 로비 전경: 접수대, 엘리베이터, 계단 입구, 소파 셋 |
| `lift` | 엘리베이터 과제와 엘리베이터 앞 | 거울처럼 매끈한 문, 층 표시등 B6, 아래 방향 버튼 패널 |
| `sofa` | 소파 과제 | 벽의 액자, 나란한 소파 셋, 접수대 쪽 램프 |
| `stairs` | 계단 과제와 계단 아래 | 어둠으로 이어지는 계단, 난간 기둥 |

### `vending` (정전: 이야기 내내 어둡다)

| 장소 | 나오는 곳 | 그림 |
| --- | --- | --- |
| `room` | 도착, 사건, 휴식, 마지막 결정 | 정전된 지하 2층 휴게실: 잠긴 문, 탁자, 푸른 빛이 번지는 자판기 |
| `item` | 받는 것 과제 | 자판기 앞면의 투입구와 "무엇이든 넣으세요" |
| `button` | 버튼 과제 | 이름 없는 버튼 세 개와 그 아래의 전선 세 가닥(빨강·파랑·초록) |
| `change` | 거스름돈 과제 | 딸각거리는 반환구와 동전, "그대로 두고 떠나세요" 표지 |

## 새 장소를 늘리려면

1. 시나리오 파일에서 장면(또는 과제)에 `place: '<장소>'`를 단다. 비운 장면은 앞 장면의 장소를 이어받는다.
2. 이 폴더에 `<시나리오 id>/<장소>.webp`를 넣는다. 그림이 없는 동안에는 기존 배경만 보인다.
3. 정전처럼 이야기가 정한 어둠은 장면에 `dark: true`(풀 때는 `false`)를 단다.
