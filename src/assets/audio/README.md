# 소리 파일 넣는 곳

**파일만 넣으면 바로 소리가 난다.** 코드를 고칠 필요가 없다. (개발 서버를 켠 채로 넣으면 새로 고침, 빌드할 때는 자동으로 묶인다.)

```
src/assets/audio/
  sfx/   효과음  — 짧은 소리 한 번
  bgm/   배경음  — 이어서 반복되는 곡
```

- 파일 이름이 곧 **소리 id**다. `sfx/select.ogg`, `bgm/night.mp3`처럼 id + 확장자(`ogg` · `mp3` · `wav` · `m4a`).
- 같은 id에 `select.ogg`, `select-2.ogg`, `select-3.ogg`처럼 `-숫자`를 붙이면 **여러 개 중 무작위**로 하나가 난다 (효과음만. 배경음은 첫 번째 파일을 쓴다).
- 파일이 없는 효과음은 임시 합성음이 난다. 합성음이 없는 소리(`type`)와 배경음은 파일이 없으면 조용하다.
- 소리 크기가 파일마다 다르면 [src/ui/audio.ts](../../ui/audio.ts)의 `SFX`·`BGM`에서 `volume`(0~1)을 맞춘다. 같은 소리가 너무 잦으면 `minGap`(ms)을 늘린다.
- 소리는 화면 위의 **소리 켬/끔** 버튼으로 켠다 (기본은 꺼짐). 켜면 음량 막대가 나온다. 브라우저 규칙상 첫 클릭 뒤부터 난다.
- 개발 중에는 브라우저 콘솔에서 `__sounds()`를 부르면 어떤 소리에 파일이 몇 개 연결됐는지 표로 나온다.

## 효과음 (`sfx/`)

| id | 나는 순간 |
| --- | --- |
| `type` | 글자가 한 글자씩 찍힐 때 (아주 짧고 작게. 55ms보다 잦게 나지 않는다) |
| `select` | 선택지를 눌러 고를 때 |
| `cancel` | 고른 것을 다시 눌러 취소할 때 |
| `ready` | "계속" 버튼을 누를 때 |
| `open` · `close` | 오른쪽 정보 패널을 열 때 · 닫을 때 |
| `draw` | 동률 추첨에서 불빛이 한 칸 넘어갈 때 (빠르게 여러 번) |
| `land` | 동률 추첨이 한 선택지에 멈출 때 |
| `good` | 결과가 나쁘지 않을 때 (변화 칩이 나타나는 순간) |
| `bad` | 부상·정신력 감소처럼 대가를 치를 때 |
| `death` | 아주 큰 충격 (화면이 흔들리는 결과) |
| `fragment` | 새 단서를 알아낼 때 |
| `item` | 아이템을 얻을 때 |
| `dim` | 조명이 한 단계 어두워질 때 |
| `blackout` | 조명이 완전히 꺼질 때 (암전) |
| `dusk` | 낮에서 밤으로 넘어갈 때 |
| `dawn` | 밤이 지나 새 낮이 올 때 (하루가 지남) |
| `ending-true` · `ending-good` · `ending-neutral` · `ending-bad` | 엔딩에 닿았을 때 (진 · 좋은 · 보통 · 나쁜) |

## 배경음 (`bgm/`)

곡은 상황에 따라 **서로 겹쳐 서서히 바뀐다** (1.4초). 반복해도 어색하지 않게 끝과 처음이 이어지는 곡이 좋다.

| id | 깔리는 때 |
| --- | --- |
| `lobby` | 대기실 (방에서 대상을 고르는 동안) |
| `day` | 낮 장면 |
| `night` | 밤 장면 |
| `dark` | 조명이 절반 넘게 어두워졌을 때 (낮밤보다 우선) |
| `ending` | 엔딩 화면 |

우선순위는 엔딩 > `dark` > `night` > `day`다 (`ScenarioScreen.tsx`의 `track`).

## 새 소리를 더하려면

1. `audio.ts`의 `SfxId`(또는 `BgmId`)에 id를 더하고 `SFX`(또는 `BGM`)에 `when`·`volume`·`minGap`(·임시 `synth`)를 쓴다.
2. 소리가 나야 할 곳에서 `playSfx('새-id')`(배경음은 `useMusic('새-id')`)를 부른다.
3. 위 표에 한 줄 더하고 파일을 넣는다.
